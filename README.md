# pairwise-hdr-metadata

同一支 HDR 片子在高亮电视上正常，接到普通电视后高光全糊，字幕还刺眼：HDR10 的 MaxCLL/MaxFALL 没写进容器，色调映射按固定 1000nit；PQ 解码后输出设备是 HLG，亮度曲线没切换；SDR 兼容层没做 tone mapping，暗部压黑；字幕按 SDR 亮度渲染，HDR 下过曝；剪辑点前后元数据不同，跨片段沿用上一段；硬解输出 10bit，中间格式却转 8bit；色彩空间标记丢失，播放器按 BT.709 解释 BT.2020；截图和缩略图直接截 HDR 帧，颜色发灰；多轨只处理主轨，封面轨没元数据；缓存按视频 ID，换片源仍用旧元数据；HDR10+ 动态元数据逐帧变化，却只读第一帧；显示器能力探测失败后回退到 SDR，没有重新协商；色调映射算子在场景切换时没重置，暗场突然提亮。media/hdr_metadata.py 是核心，tests/test_hdr_metadata.py 15个红。要修的是：静态元数据；PQ/HLG 适配；SDR 映射；字幕亮度；分段元数据；10bit 链路；色彩空间标记；截图映射；多轨元数据；缓存版本；动态元数据；能力重协商；算子重置。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
